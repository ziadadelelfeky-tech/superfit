# سوبر فت — إزاي تسطّبه

## الطريقة 1: تطبيق على الموبايل من غير أي حاجة (أسهل)
افتح لينك سوبر فت في كروم، ومن القايمة (⋮) اختار **إضافة إلى الشاشة الرئيسية**.

## الطريقة 2: ملف APK حقيقي لأندرويد (مجاني)
1. اعمل حساب على github.com، واعمل Repository جديد اسمه `superfit` (Public).
2. ارفع كل الملفات اللي في الفولدر ده: `index.html` و `manifest.json` و `sw.js` والأيقونتين.
3. من Settings ← Pages: اختار Branch `main` واضغط Save. بعد دقيقة هيبقى عندك لينك زي:
   `https://اسمك.github.io/superfit/`
4. افتح **pwabuilder.com**، وحط اللينك ده واضغط Start.
5. اضغط **Package For Stores** ← **Android** ← Generate، وحمّل الملف.
6. جوه الملف هتلاقي `.apk`. ابعته لموبايلك وسطّبه (هيطلب منك تسمح بتثبيت تطبيقات من مصادر غير معروفة).

التطبيق بيشتغل من غير نت بعد أول فتحة، وبياناتك بتتحفظ على موبايلك.

## الطريقة 3: تشغيل مباشر
افتح `index.html` بأي متصفح، وهيشتغل على طول.
